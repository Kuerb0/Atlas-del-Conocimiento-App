# Atlas del conocimiento

Biblioteca estadística personal para Windows: funciones probadas (muchas portadas de SAS), guías de teoría y una tabla SAS ↔ Python, con un visor en forma de árbol y una página de IA (entrenamiento y chat con Ollama).

- **Qué hay y dónde:** [INDEX.md](INDEX.md).
- **Tests:** `ejecutar_tests.bat`.
- **Trabajar con Claude Code:** [README_CLAUDE_CODE.md](README_CLAUDE_CODE.md).
